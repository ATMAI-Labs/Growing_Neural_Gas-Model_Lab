# Support

This is a public research project, not a supported production service.

- Use a bug-report issue for reproducible repository defects.
- Use an experiment-proposal issue for new empirical work.
- Use a research/reference issue for papers, repositories, or corrections to
  the evidence map.
- Use a pull request only when there is a concrete reviewable change.
- Report security or sensitive-data concerns privately as described in
  [SECURITY.md](SECURITY.md).

Questions about private ATMAI systems, unpublished research, clinical data, or
commercial deployments are outside this public repository's support scope.
