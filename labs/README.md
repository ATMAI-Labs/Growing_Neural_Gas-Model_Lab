# Labs

Each lab represents a durable research question. It is not a personal
workspace.

Create a lab only after its proposal issue is accepted:

1. Copy `templates/lab/`.
2. Assign the next unused three-digit ID.
3. Replace every placeholder in `lab.json` and `README.md`.
4. Add at least one proposed experiment from `templates/experiment/`.
5. Run the repository validator and open a draft pull request.

The initial lab is [`001-canonical-gng`](001-canonical-gng/), which establishes
the reference behavior required before ATMAI proposes a new model.
