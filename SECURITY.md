# Security policy

## Supported state

| Area | Support |
| --- | --- |
| Current `main` branch and latest release | Supported |
| Active experiments | Best-effort research support |
| Archived or superseded experiments | Not supported |

## Report privately

Do not open a public issue for:

- exposed credentials or secrets;
- unsafe GitHub Actions behavior;
- dependency or code vulnerabilities;
- accidentally committed personal, clinical, confidential, or restricted data;
- a method to bypass repository protections.

Use **Security → Advisories → Report a vulnerability** on this GitHub repository.
This creates a private report visible to maintainers.

Include the affected path or revision, impact, reproduction steps, and any safe
mitigation you know. Do not include real patient data, live credentials, or
unnecessary exploit material.

Maintainers aim to acknowledge a report within five business days and provide a
triage update within ten business days. Remediation and disclosure timing depend
on severity, affected users, and coordination needs.

## Public research limitations

This repository is pre-alpha research software. It is not approved for clinical
use, safety-critical decisions, or processing sensitive production data.
